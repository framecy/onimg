真实渲染

375 / 1440 / 1920，深色 + 浅色；无横向溢出。

  • 375px：前后台左右边距 16；顶栏 48；底部抽屉贴底。
  • 768px：侧栏 240；内容 gutter 24；页头与内容左边界对齐。
  • 1440 / 1920：切遍后台 tab，内容左边界不跳（页面管理 1600）。
  • 前台页脚与 main 左右边界对齐。
  • 按钮/输入 8、卡片 12、弹层 16；所有间距是 4 的倍数。
  • 控件高度已对齐：全宽按钮 36、输入 36、导航 40、关闭 32、表头 40、表格操作 28。
  • 无 <11px 持久文字；暗色登录按钮对比度 17.1:1。
  • 移动弹层从底部升起，上圆下直，不悬空。
保留的例外：Logo/头像固定深色渐变（品牌标记）、图表多色系列（已收敛为中性 + 语义色）、设备授权兜底页的内联色值。v3 预览页只作历史参考，token 以 v4 文档为准。
