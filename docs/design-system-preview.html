Onimg 设计系统 v3

Monochrome —— 参考 Linear / Vercel / Notion 的极简中性路线 + Notion 的手绘线条插画。 全站无彩色强调：层次交给中性灰阶 + 边框；主按钮高对比黑/白；插画用手绘线条 + 有机曲线 + 留白表达。 本页为完整审查预览，token 即最终落地 aperture.css @theme 的值。

与旧版（Aperture v2）核心差异： ① 背景 #0c0b10（带紫）→ #0f0f11（纯中性）； ② 品牌色 #7c5cff（紫）→ 无品牌色，强调用中性黑/白； ③ 主按钮「浅紫实心」→「白/黑实心」；④ 选中态去竖条/圆点，仅背景+文字变化； ⑤ 新增一整套手绘线条插画（空状态 / 404 / 上传 / 搜索 / 成功 / 文档），纯 SVG + CSS 变量，随主题切换。

11手绘插画 Illustration

参考 Notion 的手绘线条插画：用有机曲线、不规则手绘圆、简笔小人、星点火花营造 涂鸦般的松弛感与气质，而非机械几何。单色中性（tx-2 / tx-3 / bd-2）， 语义色仅用于成功插画，大量留白，无渐变无阴影。全部为内联 SVG + CSS 变量，随主题切换。
